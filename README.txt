SUBASH GRAMANI — PERSONAL PORTFOLIO WEBSITE
============================================

Files:
- index.html      Main website
- styles.css      Responsive visual design
- script.js       Mobile navigation and current year
- favicon.svg     Browser tab icon
- robots.txt      Search crawler guidance
- sitemap.xml     Sitemap for search engines

BEFORE PUBLISHING — IMPORTANT
1. Create a free account at https://github.com/
2. Create a PUBLIC repository named exactly:
   YOUR-USERNAME.github.io
   Replace YOUR-USERNAME with your GitHub username.
3. In index.html, replace every occurrence of:
   https://YOUR-USERNAME.github.io/
   with your actual GitHub Pages website URL.
4. In robots.txt and sitemap.xml, replace the same placeholder URL.
5. The supplied LinkedIn profile and email address are already added. Review them before publishing.
6. Add your professional email/contact method only if you want it public.
7. Upload all website files to the root of the repository.
8. In GitHub repository: Settings > Pages > Build and deployment:
   - Source: Deploy from a branch
   - Branch: main
   - Folder: / (root)
   - Save
9. Wait for GitHub Pages to publish. Your URL will be:
   https://YOUR-USERNAME.github.io/

GOOGLE INDEXING
1. Open https://search.google.com/search-console/
2. Add a URL-prefix property using your published https:// URL.
3. Verify ownership using the HTML file or HTML tag method Google provides.
4. Submit https://YOUR-USERNAME.github.io/sitemap.xml in Sitemaps.
5. Use URL Inspection for the homepage and click Request Indexing.

NOTES
- Publishing does not guarantee Google indexing or a top ranking.
- Google rankings take time and depend on relevance, quality, trust and competition.
- Check every personal fact and update dates, qualifications, role details and links before publishing.
- Do not publish private phone numbers, home address, identity documents or confidential company information.
